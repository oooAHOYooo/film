Microscope Feed

Use this page to preview the Ipevo2 or any other capture device and feed it into OBS, a browser window, or a full-screen monitor for the creature setup.

Ready. This page needs a secure context. Run it from http://localhost or another local server, not from file://.

OBS setup options:

  • Window Capture this page, or use Browser Source if you host it locally.
  • Select the Ipevo2 camera from the dropdown if multiple devices appear.
  • Use full-screen on the Linux box if you just need the microscope image on set.

If the camera looks inverted, flip it in OBS with a vertical or horizontal transform.
