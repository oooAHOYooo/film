## 🛠️ Status Definitions & Action Items

> [!NOTE]
> The storyboard compiler uses `.md` files in `scenes/` to extract captions and camera details for the web gallery. If a scene is **PDF Only**, the gallery will show generic board numbers instead of rich, descriptive shot captions.

* **✅ Complete:** No immediate action needed.
* **📄 PDF Only:** **Action:** Create `SXX - SL.md` in `pages/summer/storyboard-system/scenes/` using the shot captions from the PDF so the compiler can parse them for the web gallery.
* **📝 Shot List Only:** **Action:** Storyboard these scenes in Storyboarder (or your design tool of choice) and export them as `sXX-d1.pdf` into `pages/summer/storyboard-system/pdfs/`.
* **❌ Unstarted:** **Action:** Write the scene shot list in `scenes/` and sketch the storyboards.

## 🚀 Quick Step-by-Step Instructions

1. **When you draft a new Shot List (`SXX - SL.md`):**
   - Save it in `pages/summer/storyboard-system/scenes/`
   - Run the compiler script to update `manifest.json` and generate the fresh database:
     ```bash
     node pages/summer/storyboard-system/compile.js
     ```
2. **When you sketch new frames in Storyboarder:**
   - Save/Export them as a PDF in `pages/summer/storyboard-system/pdfs/` using the name format `sXX-d1.pdf` (e.g., `s08b-d1.pdf`).
   - Run the PDF compiler:
     ```bash
     node pages/summer/storyboard-system/compile-pdfs.js
     ```
   *(Note: The system automatically picks up the modification times and updates the dashboard!)*
