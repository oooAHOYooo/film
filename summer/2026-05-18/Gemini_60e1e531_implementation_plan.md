# Implementation Plan: Call Sheet Spaces for Notes, Props, and Wardrobe Mentions

This plan details how we will integrate spaces for **notes**, **prop lists**, and **wardrobe mentions** in the daily call sheets generated by `pages/summer/compile-production.js`.

We will make this system highly automated and flexible:
1. **Dynamic default values**: Automatically pull characters' default wardrobes from `pages/summer/props/wardrobes.md`, and list the scene key elements for props.
2. **Explicit overrides**: Allow specifying day-level `notes`, `props`, and `wardrobe` arrays/strings in `pages/summer/production-data.json`'s `shootPlan` array.
3. **Print-ready write-in spaces**: Provide elegant dotted lines/checklists on the printed page for any missing or additional information so the crew can write notes on the fly.

---

## Proposed Changes

### 1. `pages/summer/compile-production.js`

We will modify this file to:
- **Parse wardrobes**: Add `loadWardrobeData()` to read and parse `pages/summer/props/wardrobes.md`.
- **Integrate data in compiler**: Update the `compile()` function to load this wardrobe map and pass it to `generateDayHtml()`.
- **Render sections**: Update `generateDayHtml()` to construct three beautifully styled, print-friendly cards below the crew call banner and above the scene schedule:
  - **📝 Daily Notes & Safety**: Displays `planEntry.notes` if provided (as checkboxes/text), or prints blank dotted write-in checkboxes for crew notes.
  - **📦 Prop Checklist & Gear**: Displays `planEntry.props` if provided (as checkboxes), and auto-lists scheduled scenes' `keyElements`. Prints additional empty checklines if needed.
  - **👕 Wardrobe & Continuity**: Displays `planEntry.wardrobe` (daily instructions) if provided, and loops through the day's scheduled characters to print their default wardrobe from `wardrobes.md`. If a character isn't listed in the md, it renders a neat write-in line.

### 2. `pages/summer/production-data.json`

We will add sample `notes`, `props`, and `wardrobe` entries under `shootPlan` days (e.g., Day 5 and Day 9.5) to provide a clear demonstration of the override schema.
